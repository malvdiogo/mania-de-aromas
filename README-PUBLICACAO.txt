# Prévia estática — Mania de Aromas

## Como publicar
1. Extraia este ZIP.
2. Copie `index.html` e a pasta `preview-assets` para a raiz do repositório `mania-de-aromas`.
3. Substitua o `index.html` anterior quando solicitado.
4. No GitHub Desktop, faça Commit e depois Push origin.
5. No GitHub, abra Settings > Pages e confirme `Deploy from a branch`, branch `main`, pasta `/ (root)`.

## Importante
Esta é somente uma prévia visual estática. Não possui carrinho funcional, login, painel administrativo, pedidos ou ligação com SQLite/Node.js.

Este pacote não contém `.env`, banco de dados, `node_modules` ou arquivos privados.
